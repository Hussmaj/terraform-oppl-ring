# Terraform & AWS – Kom i gang med IaC

Dette prosjektet inneholder mine aller første skritt innen **Infrastructure as Code (IaC)** ved bruk av HashiCorp Terraform og Amazon Web Services (AWS).

Prosjektet er utviklet og kjørt i et **WSL (Ubuntu Linux) -miljø på en Windows-maskin, med Visual Studio Code som koderedigeringsverktøy.

## Hva prosjektet inneholder
* `main.tf`: Terraform-konfigurasjonen som ble brukt til å rulle ut infrastruktur.
* `JOURNAL.md`: En detaljert arbeidslogg som beskriver fremgang, utfordringer, feilsøking i AWS (IAM/rettigheter) og hva jeg har lært underveis.

## Teknologier brukt
* **HashiCorp Terraform** (v1.16.0)
* **Amazon Web Services (AWS)** (EC2 / Ubuntu 24.04 LTS-server)
* **WSL / Ubuntu Linux** og Bash-terminalen
* **Git & GitHub** for versjonskontroll

*For en dypere forklaring av prosessen og feilsøkingen som ble gjort, sjekk ut [JOURNAL.md](./JOURNAL.md).*
